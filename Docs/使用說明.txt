Windows 設定工具（目前預設 NUC8i7HV/HN 硬體設定檔）
更新：2026-11-07，共19個模組

執行前
- 先完成 Windows 11 安裝，登入要設定的本機管理員帳號，並準備帳號現有密碼。
- 使用者名稱、家目錄與 SID 依目前帳號取得，不固定 nuc。請勿以另一個管理員帳號代替目標使用者執行。
- 完整流程需要連網下載 Windows Update，以及尚未安裝的 OpenSSH 元件。
- 請先設定每臺電腦唯一的名稱，例如 NUC-001、NUC-002。
- 目前 Downloads 的 windows_setup 是自包含主版本；資料夾可改名；整包複製到任意可寫入、非桌面路徑即可使用，不強制在 Downloads。
- 4 個驅動封存檔與 manifest.json 已在 Modules\Drivers\Payload，不依賴外部 Driver 資料夾。請保留整個目錄與隱藏的 .git。
- 桌面清理會永久刪除使用者桌面和共用桌面的普通檔案、資料夾及捷徑。執行前請自行取走需要的資料。
- 四個桌面圖示範本以繁體中文 Windows、1920×1080、100% 縮放為準。

使用方式
1. 先在正式帳號桌面執行 Init.cmd 完成 SSH，再雙擊 Windows.cmd，允許管理員權限，輸入目前帳號的現有密碼。
2. 等待各階段結束。進度與結果以中文顯示，錯誤會記錄在 Reports\Setup-Result.json。
3. 依提示手動重新開機，登入相同帳號，再執行 Windows.cmd -AfterRestart。此入口會重試同一臺電腦同一帳號先前失敗的模組、再跑更新及清理，最後驗收。
4. 更新可能分多輪，若再次要求重新開機，手動重開後再執行 Windows.cmd -AfterRestart。
5. 單純檢查使用 Windows.cmd -VerifyOnly，不安裝更新或重套偏好。
6. 模組各有同名 .cmd，可以獨立執行；支援 VerifyOnly 的模組可用 .cmd -VerifyOnly。

執行順序
01 Apply-AutologonSettings：以目前帳號設定自動登入；密碼透過 Microsoft Autologon 儲存，不寫在工具包腳本。
02 Apply-PagefileSettings：停用磁碟分頁檔；重開機後完全生效。
03 Apply-PowerSettings：插電時停用自動睡眠和休眠；保留螢幕逾時設定。
04 Apply-SSHSettings：安裝並啟用 OpenSSH Server；自動啟動，防火牆限制 LocalSubnet。
05 Install-Drivers：核對機型、驅動 SHA256，安裝適用驅動並檢查異常裝置。
06 Apply-AMDPrivacySettings：拒絕 AMD Software 地理位置存取。已顯示的提示需手動關閉。
07 Install-WindowsUpdates：執行本輪 Windows 建議更新，顯示心跳進度並記錄是否需要重開機。
08 Apply-Debloat：先呼叫 Remove-OneDrive.ps1 解除安裝 OneDrive，再依 Debloat-Apps.txt 清理預裝 App，包含 Xbox App、Game Bar、相關登入與語音元件，以及存在時的 Gaming Services。Windows 不可移除的 XboxGameCallableUI 保留。
09 Apply-CopilotSettings：移除獨立桌面版 Copilot。
10 Apply-TaskbarSettings：隱藏搜尋、天氣/小工具與工作檢視；僅釘選 Edge。登入後自動解除暫時釘選原則。
11 Apply-StartMenuSettings：清空釘選、隱藏推薦及全部應用程式分類區；保留搜尋、帳號和電源。程式本體仍可搜尋啟動。
12 Apply-DisplaySettings：1920×1080、標準原生100%縮放，關閉自訂縮放。
13 Apply-DesktopSettings：清空普通桌面項目，顯示本機、網路、控制台、資源回收筒。
14 Apply-ThemeSettings：Windows/應用程式深色、純黑背景；必要時重新載入 Explorer。
15 Apply-InputMethodSettings：缺少時新增英文（美國）與美式鍵盤，再設為預設；保留中文及其他語言與鍵盤順序。Win+Space 切換，已開啟視窗可能保留原輸入法，下次登入使用新預設。驗證同時核對 en-US、美式鍵盤與預設值，不只檢查順序或 override。
16 Apply-TerminalHotkey：Ctrl+Alt+T 開啟 Windows Terminal，以一般使用者權限執行。使用 RegisterHotKey 背景監聽程式，登入時透過 Startup 自動啟動。

17 Apply-ExplorerSettings：設定登錄值與 Shell 即時狀態，重新整理已開啟的檔案總管以顯示一般隱藏檔；受保護系統檔保持隱藏。

18 Remove-SetupResidue：清除空的 Windows.old、預設聯絡人/遊戲等空資料夾及具名預設捷徑；含有其他資料時保留並記錄。

19 Desktop-IconLayout：最後套用四個圖示座標，避免先前的檔案總管重新整理影響排列。重開驗收入口也會最後套用此範本。

額外入口
- Modules\Desktop\Save-Desktop-Layout.cmd：圖示移動後，將目前位置儲存成新範本。
- Modules\Updates\Show-Update-Status.cmd：查看更新進度；關閉進度視窗不會停止更新。
- Windows.cmd -VerifyOnly：檢查設定、目前顯示比例、圖示座標、開始釘選匯出、App清理、輸入法及快捷鍵程序。
- Terminal 快捷鍵日誌：%LOCALAPPDATA%\NUC8-Setup\TerminalHotkey\status.log。
  REGISTERED 表示成功註冊；LAUNCHED 表示收到按鍵並呼叫 Terminal；FAILED 1409 表示快捷鍵衝突，需要排查。

網路名稱
- 連線時使用自己的帳號與主機名稱，例如 ssh your_user@nuc-001.local；名稱解析與連線須在實機確認。
- .local 用於同網段 mDNS，訪客網路、隔離網路或跨VLAN可能無法使用。
- 多臺電腦建議路由器固定 DHCP 租約；需要跨網段時使用區域 DNS，例如 nuc-001.home.arpa。
- 沒有寫入固定 IP、個人 SSH 私鑰、hosts 站點資料或其他人的 SSH config。

跨電腦執行驗證（2026-11-07）
- 不需要 agent 或 SSH 遙控。從完整工具包的 Windows.cmd 啟動，允許 UAC，輸入目前本機管理員的既有密碼。
- 不是完全無人值守：更新/顯示設定可能需要手動重開機，再在終端執行 Windows.cmd -AfterRestart（或雙擊 Core\Verify-AfterRestart.cmd）；腳本不會自行重開或關機。
- 開始前檢查 19 個模組、必要檔案、4 個驅動雜湊、NUC 型號、64 位元 Windows、目前桌面帳號、版本及語言。
- 工具包不可放在桌面內，以免桌面清理刪到自身。工具包位置必須可寫入；若已整包複製到本機，執行本機這份即可，不需 USB 持續連接。
- 每臺結果以 Reports\Acceptance-Result.json / Reports\Verification-Result.json 為準；錯誤會顯示，不當作成功。上一臺的失敗狀態不會套到另一臺。
- Windows Update 的版本與下載內容依當時供應而變化；目標偏好相同，不保證每臺更新版本/刪除數量相同。
- Modules\Debloat\Remove-OneDrive.cmd 可單獨執行；解除安裝程式，僅清除空的預設 OneDrive 資料夾，不刪除個人資料或雲端檔案。



第04模組會建立目前使用者的 .ssh\config、.ssh\active-sites.conf 與 .ssh\config.d。既有檔案不覆寫。Hosts／SSH 站點同步框架已整合；實際主機清單與金鑰尚未加入。

第04模組也設定同網段 IPv4/IPv6 Ping 入站規則（LocalSubnet）；不關閉防火牆。名稱解析與 Ping 是不同驗證項目，.local 仍取決於同網段 mDNS 支援。
SSH 初始化會將 .ssh 設為 Windows Hidden 屬性，對齊 Linux 點號目錄的隱藏慣例；顯示隱藏項目啟用時仍可看見。

Hosts / SSH 依網路匯入框架已整合第04模組，主流程仍為19模組。獨立入口 Modules\SSH\Apply-HostsSync.cmd / Modules\SSH\Sync-Hosts.cmd / Modules\SSH\Sync-SSH.cmd。
使用目前帳號的 .config\hosts\sites.json 動態管理任意站點；Hosts與SSH可獨立或搭配，以 Outputs 個別開關。規則或來源每10秒重新讀取，未變更不重寫輸出。框架只提供空白範本，沒有任何真實IP／主機清單。
完整操作步驟及最小例子見 Modules\SSH\CustomHostsSync\使用方式.txt。SSID受定位權限限制時可改用NetworkProfile或IPv4Cidr，不會強制開啟定位。
