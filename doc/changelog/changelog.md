# 版本變更紀錄

本文件記錄使用者可見的行為、相容性及遷移要求。詳細實作與驗證紀錄見中文 Git 提交；發布版本與來源提交以 GitHub Release 為準。

## [Unreleased]

### Fixed（修正）

- 自動登入階段先完成 SecureString 密碼輸入，再顯示一鍵進度面板，避免密碼提示期間被進度畫面干擾；密碼仍遮罩輸入，不新增密碼日誌。

## [v0.2.1] — 2026-11-08

此版整合未發布 v0.2.1-rc1 的功能與後續修正。版本標題代表已準備發布；實際公開版本、對應提交與品質證據，以 GitHub Release、Actions 及 Pages 為準。

### Added（新增）

- README 提供兩條 USB 操作路徑：在地區／Wi-Fi 初始設定畫面按 Shift+F10，自動尋找 USB 後執行 Init；已有正式帳號則直接執行 Windows。保留 Ctrl+Shift+F3 稽核桌面作為可選路線，帳號建立只需一次 Init，正式帳號登入後不必重跑 Init。
- Windows 入口可自行安裝 OpenSSH Server、設定同網段防火牆並顯示連線資訊；不需先手動安裝 SSH，也不需要 agent 控制。帳號、SID、家目錄、主機名稱及工具包磁碟位置動態取得。
- 一般 Windows 電腦使用通用模組；NUC8i7HVK／HNK 驅動為可選獨立包，依板號及硬體 ID 判斷，未知型號可重新偵測或明確核對後選擇，不選包預設略過。v0.2.1 的型號獨立 ZIP 以大小、SHA256、ProfileId 及 manifest 雜湊釘選，只屬於該版本。
- 資料分享政策逐項設定及讀回；管理員提權免提示保留 UAC 啟用，提供唯讀驗證與依首份機器快照還原。首次提權仍須核准，組織政策未允許時明確回報讀回失敗。
- 報表由實際斷言與程序退出碼產生，提供 Actions 摘要、七天測試附件、Pages 簡潔報表及整體覆蓋率徽章。語言分項在報表分開計算後彙總，不以單一語言或其他提交結果代替整個儲存庫的證據；版本品質附件依來源及雜湊長期保存。

### Changed（變更）

- Release 使用 GitHub 內建 Source code ZIP；依 README 補入並驗證 Microsoft 官方 Autologon，再將整份資料夾放上可寫入 USB。驅動包另外選擇，主程式不內嵌大型驅動、Autologon EXE、個人網路規則或每機紀錄；一般使用者不需要 Go、Git、Docker 或 agent。
- 桌面、檔案總管、解析度、配色、工作列與開始選單共用受保護的互動桌面執行流程，核對原帳號、電腦、桌面與本輪結果。工作列仍於下次登入後解除暫時政策；開始選單待套用／待登入狀態如實保留，舊版政策只在其他設定完成後明確同意才套用。
- Windows Update 顯示 API 提供的下載／安裝百分比、目前項目及最後回報時間，並保留進度 JSON 與日誌。搜尋、下載失敗或逾時明確回報，保留診斷後請求中止；不自行重新開機或關機。
- 設定、清理、hosts／SSH、更新及續跑採可單獨執行的模組與具名原流程；保留每機進度及失敗資訊，重開後可用 AfterRestart 續跑；需要只讀時可用 VerifyOnly，後者不安裝驅動或再次套用偏好。
- 維護與驗收工具以 Go 為主，原生設定保留 PowerShell 5.1；Windows runner 與離線 Windows Docker 執行單元及隔離整合測試，發布與 Pages 仍須通過對應提交的完整品質門檻。

### Fixed（修正）

- Terminal 快捷鍵支援新帳號尚未建立或註冊 Startup 目錄的情況；保留使用者原生重新導向路徑，必要時由目前帳號的 ApplicationData 解析啟動目錄，僅在套用設定時建立目錄。
- Init 在缺少或驗證失敗的設定包上，會於詢問帳密與建立帳號前停止；修正全新使用者 SSH 說明檔路徑。Windows 階段統一負責正式帳號 SSH，避免重複 Init。
- 桌面清理會移除仍可見的普通隱藏檔，保留系統檔；套件位於桌面、祖先／別名或重新解析點可能造成誤刪時先拒絕。四個系統圖示在移動前後均須完整唯一，儲存排列不接受任意四個檔案。
- 工作列 Apply 讀回搜尋、小工具、工作檢視、配置路徑、鎖定值及 Edge-only Replace XML；寫入未生效不再回報成功。登入收尾以固定受保護工作執行，舊一輪不會清掉較新的政策、RunOnce 或工作，尚未收尾也不會假通過。
- Windows Update 與 GUI 不再從可被一般使用者替換的固定公開 stage 執行程式；來源、權限、雜湊及當次身分不符時停止，舊日誌不作為本輪成功證據。
- 官方下載共用函式先確認目標路徑與暫存資料，容器建置同步保留必要來源；修正 Windows 容器環境差異及 workflow 語義驗證，失敗不能被略過或舊快取掩蓋。
- 公開入口、徽章與歷史報表核對來源提交及量測時間；部署失敗時保留上次成功報表，Release 標題僅使用版本號，不以過期附件回填新版本。

## [v0.2.0] — 2026-11-07

### Changed（變更）

- Windows 主流程以通用 Windows 為預設；驅動移至獨立可攜包，只有相符 NUC 主機板且明確選包才安裝，直接 Enter 預設略過。其他機型不再因 NUC 機型檢查被阻擋。
- 版本檔、版本準備命令、PR 與 ci-rollup 統一發布流程；標籤須對應 main 歷史、版本檔與 changelog。
- RC 發布標為預覽版；正式版整合同版 RC 紀錄。使用 GitHub 內建來源下載，不再上傳重複的來源 ZIP 與 SHA256。

- 測試分為 Unit／Integration／System，CI 明示 System／E2E 未執行，避免將隔離測試當作完整安裝驗證。
- 自有目錄改小寫與底線，更新入口與路徑映射；維護工具分至 script/test、script/release、script/package，交付執行樹不依賴測試或發布工具。新驅動日誌使用 driver_logs；既有 ProgramData／排程識別及第三方原始內容保留。

- 通用流程不代表已在每種硬體完成實機驗收。現有 NUC 驅動僅提供給相符設定檔，其他硬體需使用自己的 Windows Update 或原廠驅動。
- v0.1.x 既有 Release、來源資產與標籤保持原樣。

## v0.1.2 — 2026-11-07

### Changed（變更）

- 完整安裝、來源包準備、獨立模組、測試及發布說明集中於根目錄 readme.md，依正式專案格式提供目錄與快速開始。
- 版本紀錄移至 doc/changelog；移除重複的 Docs 文件。舊「使用說明.txt」路徑別名仍解析到 readme.md。

### Removed（移除）

- 不再維護根目錄 changelog.md 或重複使用說明。從舊版本找文件時，請改讀 readme.md 與本文件。

## 初始公開版本系列（v0.1.x）

### Added（新增）

- 可選獨立驅動包改採根目錄 drivers 的資料型機種設定檔；NUC8i7HVK／HNK 依板號及精準硬體 ID 更新 12 個已核官方套件，保留必要 SWC、CAT 與完整 payload 雜湊。完成設定及重開後可唯讀重新盤點官方目標，較新版本不降版；一般電腦未選包仍略過。


- Init 提供本機帳號及 SSH 初始化；Windows 入口依模組執行設定，支援重新開機後續跑及只讀驗收。
- 提供自動登入、電源、分頁檔、更新、預裝 App／OneDrive 清理、工作列、桌面、深色背景、英文美式鍵盤與 Terminal 快捷鍵模組。
- SSH 與 hosts 可獨立同步，站點規則由目前使用者動態維護；公開範本不包含私人主機清單或金鑰。
- Windows CI 執行語法與隔離測試；版本標籤通過測試後發布來源 ZIP 與 SHA256。CI 報告短期保存，實機續跑紀錄留在原機。

### Changed（變更）

- 對外產品名稱為 Windows 設定工具，儲存庫為 windows_setup；發布包採 windows_setup_vX.Y.Z_source.zip，根目錄 windows_setup/。
- 完整工具包可整包搬移到可寫入且非桌面的路徑，動態取得帳號與工具包位置，不固定使用者名稱或磁碟代號。
- 目前 Windows 一鍵硬體設定檔與內建驅動仍限定 NUC8i7HV/HN；其他硬體並未因改名而自動支援。既有 ProgramData 與續跑識別保留。

### Security（資料保護）

- Git 與來源發布包排除帳號暫存、私鑰、個人網路規則、每機紀錄及安裝二進位；完整包仍須自行補齊可信來源的 Autologon 與驅動並通過檢查。

### 驗證界限

雲端測試驗證來源與隔離邏輯，不能代替新電腦的 OOBE、更新、驅動、登入與顯示驗收。Windows 版本與硬體差異可能影響結果。
