# 版本變更紀錄

本文件記錄使用者可見的行為、相容性及遷移要求。詳細實作與驗證紀錄見中文 Git 提交；發布版本與來源提交以 GitHub Release 為準。

## [Unreleased]

### Added（新增）

- 可選獨立驅動包改採根目錄 drivers 的資料型機種設定檔；NUC8i7HVK／HNK 依板號及精準硬體 ID 更新 12 個已核官方套件，保留必要 SWC、CAT 與完整 payload 雜湊。完成設定及重開後可唯讀重新盤點官方目標，較新版本不降版；一般電腦未選包仍略過。

- Windows Update 顯示API提供的下載與安裝百分比、目前項目及最後回報時間，README提供進度JSON與即時日誌查閱命令。搜尋或下載失敗不再當作沒有更新或被快取掩蓋；逾時先保留診斷再請求中止，仍不自動重新開機。


- Windows 第 1 階段新增此電腦管理員提權免提示，僅設定 ConsentPromptBehaviorAdmin=0，保留 UAC 啟用及其他政策；提供獨立執行、只讀驗證與依首份機器快照還原。第一次提權仍需核准，組織政策覆寫會讀回失敗。


- 清理階段新增可獨立執行及 VerifyOnly 的非必要資料分享政策：依版本設定診斷最低支援級別，關閉廣告識別、診斷個人化、活動歷程、回饋提示、雲端語音及手寫輸入改善分享。逐項讀回並記錄結果；專業版仍保留必要診斷，雲端語音關閉會影響 Win + H。

### Fixed（修正）

- 發布與 Pages 工作的覆蓋率工具路徑改在合法的 step env 設定，避免 GitHub 在啟動工作前拒絕整份 workflow；CI 與離線容器增加固定 actionlint 語義驗證及正負控制樣本。

### Changed（調整）

- SYSTEM 更新工作改用受保護的獨立目錄：原子建立 SYSTEM／管理員 ACL，檢查祖先與重新解析點、獨占複製及完整來源雜湊。舊日誌原位保留，結果依電腦、原啟動者與本輪 ID 驗證；不再執行一般使用者可替換的 stage。


- hosts 安裝編排與殘留清理採具名函式庫，保留原帳號、路徑及資料保護規則，讓隔離測試可直接驗證交付原始碼。套件檢查同步要求新增函式庫；清理系統磁碟不受當前工作目錄影響。

## [v0.2.1-rc1] — 2026-11-08

此版本為預覽版。測試及覆蓋率以對應提交的 CI 與不可變 Release 證據為準，不以 main 新結果回填歷史版本。

從本版 Release 的 Source code ZIP 取得程式後，依根目錄 readme.md 從 Microsoft 官方取得並核對 Autologon，再執行套件檢查；來源 ZIP 不是完整離線包，NUC 驅動仍為可選獨立包。README 包含 USB 初始設定及既有帳號兩條操作路徑。
### Added（新增）

- 可選獨立驅動包改採根目錄 drivers 的資料型機種設定檔；NUC8i7HVK／HNK 依板號及精準硬體 ID 更新 12 個已核官方套件，保留必要 SWC、CAT 與完整 payload 雜湊。完成設定及重開後可唯讀重新盤點官方目標，較新版本不降版；一般電腦未選包仍略過。

- Windows 與獨立驅動入口先顯示主機板偵測；支援 NUC 才詢問獨立包，未知型號可重新偵測、通用略過，或核對整機／板號後明確確認。相鄰包須確認才使用，缺失或雜湊失敗可重選；無互動主控台不等待輸入。確認只影響驅動且保存原始證據，同機同帳號續跑會重新偵測，已知其他機型、多板或衝突拒絕強裝。

- 報表區分整體自有程式碼覆蓋率與語言分項，README 僅顯示整體徽章；三份可核對證據隨新版本永久保存。正式 Pages、Release 與部署後驗收強制完整量測及精確 80%，新版附件固定 11 個並禁止降級發布，歷史附件契約維持不變。

- 新增 Windows Docker 開發與全套隔離測試入口，真容器測試及其報告需求驗收納入 ci-rollup；容器證據獨立短留七天，不冒充 Windows 桌面或完整安裝 E2E。


- 新增 PR／main 需求驗收門檻與 Pages 部署後匿名 HTTPS 驗收，檢查真實來源、報告一致性、入口與徽章；CDN 只有限重試，人工視覺與實機驗證不冒稱自動通過。

- 依真實斷言與程序結果自動產生分層 HTML／JSON／JUnit 報表及 SVG 徽章；main 公開報表由 Pages 更新，PR 僅保留七天去識別附件。
- 依使用者決定移除 System／完整安裝實機驗收的交付要求與報表占位；保留產品重開後續跑、VerifyOnly 及每機紀錄。
- Pages 僅保留自行產生的簡潔測試摘要、來源、整體覆蓋率、語言明細及操作入口，移除版本比較程式與無證據面板。
- 版本品質快照由 Release 長期保存，Pages 使用原始量測時間重建；舊版沒有快照時不回填假結果。

### Fixed（修正）

- 獨立模組與直接儲存桌面排列的提權入口保留原始使用者 SID，拒絕使用另一個管理員帳號套用或儲存設定。
- 主流程及獨立桌面清理在刪除前拒絕套件位於桌面本身或子目錄；SSH 排程 worker 保留原始套件位置與安全檢查依賴，避免搬到 ProgramData 後漏判。
- SSH 安裝與驗收共同核對本工具規則為啟用、入站允許、Any 設定檔、TCP 22 與唯一 LocalSubnet；既有規則會修正協定和連接埠。這不取代實際連線或其他防火牆／GPO 檢查。
- 公開摘要核對可見提交、量測時間、整體覆蓋率及範圍，不接受過期或以單一語言冒充整體的結果。
- GitHub Release 顯示標題只使用版本號，保留正文、標籤與不可變品質附件契約。

- 修正真實 Windows 容器建置中 PATH 插值遺失系統工具路徑的問題，明確保留系統搜尋路徑並在建置與測試前確認必要工具可用。

- 公開部署驗收使用明確狀態條件，避免 main 不發布 Release 時，祖先工作略過導致真正 HTTPS 驗收也被略過。


- 測試入口首頁先顯示本次程式檢查結果、時間與使用步驟；歷史頁以原始證據整理並標示來源，不覆寫不可變原始附件。

- 品質徽章對齊 base 上方原生 CI 的 flat 圓角外觀、字體與自適應寬度，保留 Branch／Release、未執行及未量測狀態，不產生虛構覆蓋率。

- 修正首次初始化 SSH 使用者目錄時的說明檔來源路徑，使用實際 custom_hosts_sync 目錄；新增全新暫存使用者目錄的初始化與驗證回歸測試。


- 主流程遇失敗先寫結果再回傳非零退出碼；驅動解壓快取依雜湊隔離，驗證以本輪識別與擁有者拒絕舊報告，Windows Update 核對完整結果數量。



### Changed（變更）

- 維護驗收工具改以 Go 為主，完整移植原 21 項 Python 契約並移除 Python 工具鏈；保留 PowerShell 原生設定與測試。釘選 Go 與官方 HTML5 解析器，CI／離線 Windows 容器／公開部署共用 Go 驗收，紅綠提交保留遷移證據。

- 補上新手從 OOBE CMD 找 USB、切換實際磁碟路徑與呼叫入口，以及桌面檔案總管位址欄開 CMD 的逐步指令；區分稽核引導、正式帳號 SSH 與重開後驗收，不假定固定盤符。

- 自有原始檔與入口統一小寫 snake_case，更新文件、CI、測試與獨立驅動包引用；保留第三方供應檔及每機記錄契約，舊失敗模組識別可映射至新版腳本。

- 主操作說明分為全新 OOBE 與既有正式帳號桌面兩條完整情境，以可寫入 USB 或本機完整工具包為起點，串接 OOBE 稽核建帳號、正式帳號 SSH、Windows 設定、手動重開與驗收；驅動包可選，不強制複製到 Downloads，並說明每次重新確認 USB 路徑及未完成 System／E2E 驗證的限制。

- 依使用者決定，在取得合適 Windows 11 x64 可丟棄測試環境前暫緩 System／完整安裝 E2E；保留未驗證狀態與 v0.2.0 預覽標記，合併仍需 PR／ci-rollup。
- 第三方來源與授權說明移至 doc/third_party.md，根 README 引用；修正相對連結與獨立驅動包位置。當時的 AGENTS.md 保留根目錄供工具自動發現；本輪改名為 agents.md 後須明確讀取，第三方授權檔不搬動。

## [v0.2.0] — 2026-11-07

### Changed（變更）

- Windows 主流程以通用 Windows 為預設；驅動移至獨立可攜包，只有相符 NUC 主機板且明確選包才安裝，直接 Enter 預設略過。其他機型不再因 NUC 機型檢查被阻擋。
- 版本檔、版本準備命令、PR 與 ci-rollup 統一發布流程；標籤須對應 main 歷史、版本檔與 changelog。
- RC 發布標為預覽版；正式版整合同版 RC 紀錄。使用 GitHub 內建來源下載，不再上傳重複的來源 ZIP 與 SHA256。

- 測試分為 Unit／Integration／System，CI 明示 System／E2E 未執行，避免將隔離測試當作完整安裝驗證。
- 自有目錄改小寫與底線，更新入口與路徑映射；維護工具分至 script/test、script/release、script/package，交付執行樹不依賴測試或發布工具。新驅動日誌使用 driver_logs；既有 ProgramData／排程識別及第三方原始內容保留。

- 通用流程不代表已在每種硬體完成實機驗收。現有 NUC 驅動僅提供給相符設定檔，其他硬體需使用自己的 Windows Update 或原廠驅動。
- v0.1.x 既有 Release、來源資產與標籤保持原樣。

## 初始公開版本系列（v0.1.x）

### Added（新增）

- 可選獨立驅動包改採根目錄 drivers 的資料型機種設定檔；NUC8i7HVK／HNK 依板號及精準硬體 ID 更新 12 個已核官方套件，保留必要 SWC、CAT 與完整 payload 雜湊。完成設定及重開後可唯讀重新盤點官方目標，較新版本不降版；一般電腦未選包仍略過。


- Init 提供本機帳號及 SSH 初始化；Windows 入口依模組執行設定，支援重新開機後續跑及只讀驗收。
- 提供自動登入、電源、分頁檔、更新、預裝 App／OneDrive 清理、工作列、桌面、深色背景、英文美式鍵盤與 Terminal 快捷鍵模組。
- SSH 與 hosts 可獨立同步，站點規則由目前使用者動態維護；公開範本不包含私人主機清單或金鑰。
- Windows CI 執行語法與隔離測試；版本標籤通過測試後發布來源 ZIP 與 SHA256。CI 報告短期保存，實機續跑紀錄留在原機。

### Changed（變更）

- 對外產品名稱為 Windows 設定工具，儲存庫為 windows_setup；發布包採 windows_setup_vX.Y.Z_source.zip，根目錄 windows_setup/。
- 完整工具包可整包搬移到可寫入且非桌面的路徑，動態取得帳號與工具包位置，不固定使用者名稱或磁碟代號。
- 目前 Windows 一鍵硬體設定檔與內建驅動仍限定 NUC8i7HV/HN；其他硬體並未因改名而自動支援。既有 ProgramData 與續跑識別保留。

### Security（資料保護）

- Git 與來源發布包排除帳號暫存、私鑰、個人網路規則、每機紀錄及安裝二進位；完整包仍須自行補齊可信來源的 Autologon 與驅動並通過檢查。

### 驗證界限

雲端測試驗證來源與隔離邏輯，不能代替新電腦的 OOBE、更新、驅動、登入與顯示驗收。Windows 版本與硬體差異可能影響結果。
